# Agent Instructions & Operating Rules

All AI agents working in this project must strictly adhere to the following rules:

## 1. Implementation Plan Required
- After every user request, you **must** formulate and present a clear implementation plan before making changes or executing actions, unless the user explicitly asks not to do so.
- Clearly specify what changes will be made, files affected, and the exact commands to be executed.

## 2. Strict Command Execution Restrictions
- **Do not run any commands** other than what is explicitly specified in the implementation plan given before you get started.
- Do not run exploratory or arbitrary commands outside of the approved implementation plan.

## 3. No Server Execution
- **Do not start or run any servers** (e.g., backend, frontend, API, development, or database servers).
- All servers are already run and managed by the user on their side.

*Note: These rules are currently active. Additional project rules may be appended as needed.*
